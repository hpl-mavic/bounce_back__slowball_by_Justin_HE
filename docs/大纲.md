## 0. 一句话

**你是一颗球。按住鼠标世界就慢下来，松手的瞬间它又快回去——用三次撞击，撞碎三滴血的守门者。**

---

## 1. 定位

| 项目 | 内容 |
| --- | --- |
| 类型 | 俯视角动作 / 弹幕（弹幕来自敌人，玩家靠撞击输出） |
| 参考 | 《Superhot》（你不动世界不动）+ 台球 / 弹珠（一次发射、反弹走位）+ 东方 Project（读弹密度） |
| 平台 | PC 键鼠优先；触屏天然适配（按住拖动 = 触摸拖动） |
| 单局时长 | 60–120 秒 |
| 目标体验 | **瞄准时世界是慢的，出手后世界是快的——每一次发射都是一次承诺。** |
| 分辨率 | 1280×720，`canvas_items` 拉伸，窗口可缩放 |

### 设计支柱

1. **发射是承诺**：拖动一次只能给一个矢量，松手之后你只能接受它。
2. **空中只有一次反悔**：1 次变向，撞墙 / 撞 Boss 才补一次。
3. **时间跟着你的运动走**：球飞起来，世界才真正开始运转。
4. **难度只考验容错率**：弹幕本身完全一样，只改主角血量和反击箭头数。

## 2. 核心循环

```
   按住左键（世界 0.1×；球保持原速继续飞）
		│  鼠标拉离球心：方向 = 球→鼠标，力度 = 距离
		│  同时看到预测轨迹（含墙与障碍物的反弹）
		▼
   松开（发射 → 世界 1.0×）
		│  球直线飞出去，穿过弹幕
		├── 撞墙 / 撞障碍物 → 反弹 +1 次变向
		├── 撞 Boss → 1 点伤害 + 被弹开 +1 次变向
		└── 滞空再按住 → 消耗 1 次变向，边飞边重瞄
		▼
   速度衰减到停下
		▼
   重复，直到 Boss 三滴血被打空
```

**为什么这样成立**：一次拖动只给一个矢量，玩家就没法"贴着鼠标实时微调"，
每一次出手都必须是"读弹 → 算反弹 → 定力度"的完整判断；而空中那 1 次变向，
就是给这个判断留的唯一一个后悔药。

## 3. 操作

一次拖动 = 一次发射。**球不会跟着鼠标走。**

| 输入 | 行为 |
| --- | --- |
| 按住左键 | 进入瞄准：世界 → 0.1×，**球保持原速继续飞**，不会停下 |
| 移动鼠标 | 矢量**从球心指向鼠标**：方向 = 球→鼠标，力度 = 球到鼠标的距离（0–230 px） |
| 松开 | 球按该矢量发射，世界 → 1.0× |
| 滞空时按住 | 消耗 1 次变向机会，边飞边重瞄 |
| 空格 | 暂停 / 继续（恢复要倒数 3 秒） |
| 窗口失焦 | 自动暂停；回来后**先点一下画面**，倒数 3 秒再继续 |
| 撞墙 / 撞 Boss | +1 次变向（最多存 3 次） |
| `1` `2` `3` | 标题界面切换难度 |
| `空格` / `Enter` | 开始 |
| `R` | 重开（保留难度） |
| `Esc` | 回标题 |

### 3.1 矢量与力度

**矢量的原点永远是球心**，不是按下鼠标的位置：

```
矢量 = 鼠标位置 − 球心位置
方向 = 矢量归一化
力度 = clamp(|矢量| / 230, 0, 1)
速度 = lerp(320, 980, 力度)
```

所以鼠标一动，箭头、力度环、预测轨迹就**实时跟着变**；按住之前（球停稳时）
也会显示一层淡色的预览，可以先瞄再按。

| 球到鼠标的距离 | 出膛速度 |
| --- | --- |
| < 24 px | 取消（球不动，不消耗变向） |
| 24 px | 约 390 px/s |
| 115 px（半程） | 650 px/s |
| ≥ 230 px（满力） | 980 px/s |

- 方向取**球→鼠标**，符合"往哪指就往哪飞"的直觉。
- 球外 230 px 处画一条刻度线：越过它力度不再增加。
- 拖动过程中实时显示：发射箭头（长度 = 力度）、力度环、**预测轨迹（含第一次反弹）**。

### 3.2 空中变向

- 每次发射自带 **1 次**；撞墙 **+1**；撞 Boss **+1**；最多存 **3 次**。
- 滞空时按住会消耗 1 次、直接进入重瞄；**球不会停**，仍以原速继续飞（世界掉到 0.1×，所以看起来慢）。
- 次数为 0 时按住无效，球身闪红环提示"锁死"。
- 球速度衰减到 80 px/s 以下判定为停稳，重置为 1 次。

## 4. 时间系统

### 4.1 规则

| 状态 | 时间倍率 | 说明 |
| --- | --- | --- |
| 抓住球 / 球停着 | **0.1×** | 瞄准、读弹、看预测线 |
| 球在飞 | **1.0×** | 世界全速，弹幕真正开始流动 |
| 结算 | 0.3× | 死亡 / 胜利的慢镜头 |

> **关于"按住 = 慢放"**：按住时球仍在飞，只是世界被压到 0.1×。所以这条规则的实质是
> "**你不松手，世界就不加速**"——想真正提速，就得松手把球打出去。

### 4.2 实现

- 全局 `Engine.time_scale` 每帧向目标值缓动（12/s），约 0.07 秒切换完成。
- 所有实体只用 `delta` 驱动（px/秒），倍率一改，子弹、Boss、粒子一起变慢。
- 时间倍率用**现实时间**推进（`Time.get_ticks_usec()`），否则慢放时切换自身也会被拖慢。
- 结算面板同时给出「现实用时 / 战场时间」，把时间压缩率变成一个可读的数字。

### 4.3 视觉反馈

- 慢放：全屏冷蓝 + 暗角加深；右上角 `0.20× / 瞄准·慢放`。
- 全速：冷色褪去；`1.00× / 飞行·全速`，进度条拉满。

## 5. 难度

| 难度 | 主角血量 | 受击反击箭头 | 体验 |
| --- | --- | --- | --- |
| 简单 | 5 | 3 | 容错高，反击方向少 |
| 普通 | 3 | 4 | 标准体验 |
| 困难 | 1 | 5 | 一碰即死，五个方向同时盯着你 |

Boss 血量（3）、环爆/扇形/螺旋的弹数与弹速、时间倍率、场地，三种难度**完全一致**。

**设计理由**：难度主要加在"犯错后的代价"上（血量），轻量地加在"读弹压力"上（反击箭头数）。
箭头决定你撞完它之后要从几个方向里躲——多一个方向就多一份要提前避开的角度，
但不会让你重新背一套弹幕。

## 6. 主角

### 6.1 数值

| 参数 | 值 | 作用 |
| --- | --- | --- |
| 半径 | 17 px | 碰撞体与视觉一致 |
| 拖动满力距离 | 230 px | 力度 = 距离 / 230 |
| 出膛速度 | 320 – 980 px/s | 力度 0 → 1 |
| 空中减速 | 215 px/s² | 直线滑行约 4 秒后停下 |
| 停稳阈值 | 80 px/s | 低于此值重置变向次数 |
| 撞墙速度保留 | 95% | 反弹损耗很小 |
| 撞 Boss 速度保留 | 88% | 撞完会被弹开 |
| 受击无敌 | 1.1 s（战场时间） | 防止一次失误连吃三发 |
| 变向次数 | 初始 1 / 上限 3 | 撞墙、撞 Boss 各 +1 |

### 6.2 判定

- 撞击 = `player` 与 `boss` 的圆形重叠，用**持续重叠检测**（每物理帧 `get_overlapping_areas()`），
  而不是只靠 `area_entered`：否则贴着 Boss 站着不会再次触发进入事件，会出现"撞不出伤害"。
- 每次命中后 Boss 进入 0.45 秒无敌（身上有一圈白色进度弧），这段时间撞上去只会被弹开。
  0.45 秒只够挡住"同一次接触被判两次"，不会拖慢连击节奏。

### 6.3 表现

- 停稳：球外一圈呼吸环，提示"可以抓了"。
- 瞄准：发射箭头 + 力度环 + 虚线预测轨迹（含第一次反弹点）+ 拖动起点的圆点。
- 飞行：拖尾 + 三道速度线 + 球下方显示剩余变向次数（小圆点）。
- 锁死：按住但没次数时，球身闪红环。

### 6.5 盾球 · 护盾

**按住右键维持，松开立刻回充。**

- 按下右键护盾**立即出现**（无渐显），松手**立即消失**；判定和视觉同一帧生效。
- 按住时护盾展开，持续时间（充能）以 1× 速度消耗，最多撑 **1.5 秒**。
- 一次开盾最多挡 **4 发**子弹（球下 4 个小点显示余量）；挡完第 4 发护盾直接**破碎**，
  并给 **0.1 秒无敌**，避免同一帧被第二发补刀。
- 松手立即关盾，充能按 **0.75/s** 恢复——从 0 充满正好 **2 秒**，这就是"冷却"。
- 充能耗尽会自动关盾，然后同样开始回充。
- 护盾期间子弹打在身上**不掉血**。

球体下方有一条**简约的绿色进度条**：按住时是剩余持续时间，松手后是回充进度。

护盾分三个阶段，由**本次开盾后经过的时间**决定：

| 阶段 | 时间 | 弧面颜色 | 弧面接住子弹 |
| --- | --- | --- | --- |
| 0 | 0.0–0.3 s | 无扇形 | 只挡子弹 |
| 1 | 0.3–0.5 s | 绿色 | **+0.5 s 充能，可超过 1.5 上限** |
| 2 | 0.5–1.0 s | 黄绿色，缩小到 0.8× | **+0.5 s 充能，但只补到 1.5 为止** |
| 3 | 1.0–1.5 s | 红色 | 只挡子弹 |

**只有扇形的"弧面"是护盾面**：两侧直线、扇形内部面积都不算。
只有从弧面穿过的子弹才会被接住并触发上面的奖励；从侧面或背后打来的，仍然只是被球体挡下、不给任何回复。

- 扇形**始终对准鼠标**，所以想拿奖励就得把弧面对准子弹来的方向——等于主动往危险里凑。
- 一阶段奖励是"续命"（能超过 1.5 秒上限，把护盾拖长），二阶段只是"补满"，三阶段零回报。
- 角色外观：**长方形机械眼 + 绿色方形瞳孔**，球体偏机械冷色。

### 6.6 入场空投（两个角色通用）
每局开始时，球从复活点上空 **170 px** 处落下：

- 下落 0.55 秒（按现实时间，不吃慢放），带 2 次缓动的重力加速。
- 伪立体：球体随高度**放大**（最高约 1.44×）并整体上移，落地时回到正常尺寸。
- 地面有一个**半透明黑圆当影子**，随下落变大变深，**落地瞬间消失**。
- 落地时震屏 + 一圈冲击波；落地前不接受操作、不吃伤害。

### 6.7 虫球 · 五段进化

**基础形态（和游球一样的青色身体，复眼）**

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 体积 | 别人的 **70%**（半径 11.9） | 更小的判定、更小的碰撞体 |
| 变向上限 | **5** 次（别人 3 次） | 空中可以连续修正四次 |
| 右键 | 世界压到 **0.05×** | 按住生效、消耗充能；**基础 2.5 s，每进化一档 ×1.3（相对上一档）**；耗尽必须松手，松手后 0.5/s 回充 |

**进化**

- 每 **碰** 满 5 次 → 进化 1 档（撞墙、撞障碍、撞 Boss 都算一次「碰」）。
- 共 5 档，25 次碰撞封顶。
- 球下一条**五格进度条**：颜色从绿到紫渐变，每格 20%；当前格按 5 次碰撞逐步填满。

**满级（5 档）后的三个特性**

1. **0.5 抗伤护盾**：每 6 秒回复一次；触发时这一下只扣 0.5 血（因此血量是浮点数，HUD 会画出"半格"）。
2. **撕裂**：撞到 Boss 的瞬间在接触点炸出几道锯齿裂口 + 粉紫色火花 + 震屏。
3. **冲刺**：撞到 Boss 后自身速度 ×1.2（上限 1500 px/s）。

> 慢放场现在有充能限制：满充能 2.5 秒，按住消耗、松手按 0.5/s 回充；
> 耗尽后会强制断开，必须松开右键才能重新蓄。

## 7. Boss 战

**两关独立可选**（标题页「关卡」一行点选）：
第一章「环」（3 血）、第二章「壁」（6 血）。每局只打一只，打完即结算。

### 7.1 概念

> 一个把自己包在多层旋转环里的核心。每被撞碎一层，它就少一圈壳，也更快。

- 血量：**3**（= 必须命中 3 次）
- 半径：54 px
- 悬浮：绕场地中心做双频正弦漂移（x 振幅 232、y 振幅 74）
- 血量可视化：**3 条环绕的弧线**，掉一滴血少一条，同时多一道裂纹

### 7.2 三阶段 = 三滴血

| 阶段 | 剩余血量 | 新增行为 | 设计意图 |
| --- | --- | --- | --- |
| 1 | 3 | 环形弹 + 三连瞄准 | 教你读环、算发射角度 |
| 2 | 2 | 加螺旋弹流 | 场地被"搅拌"，不能只站桩瞄 |
| 3 | 1 | 全部加速加密 | 最后一条命，逼你赌 |

### 7.3 弹幕表（v0.2 已降频降密）

| 招式 | 阶段 1 | 阶段 2 | 阶段 3 |
| --- | --- | --- | --- |
| **环爆**（全场均匀散开） | 9 发 / 124 px·s / 每 3.6 s | 12 发 / 134 / 每 3.1 s | 15 发 / 146 / 每 2.6 s |
| **扇形瞄准**（朝玩家，1.0s 预警） | 3 发 / 195 / 每 2.9 s | 4 发 / 205 / 每 2.4 s | 5 发 / 220 / 每 2.0 s |
| **螺旋弹流** | — | 1 臂 / 148 / 每 0.30 s | 2 臂 / 148 / 每 0.24 s |
| **受击反击**（沿箭头） | 按难度 3 / 4 / 5 发，145 px/s，朝当前箭头方向 | | |

对比 v0.1：环爆 14→9 / 18→12 / 24→15，间隔 +35%；扇形 3/5/7 → 3/4/5；
螺旋间隔 0.155→0.30；受击反击 18→10→**4**。**子弹总量大约减半**，
因为现在玩家在飞行中无法微调，需要更多可以穿过的缝隙。

- **环爆（有预警）**：发射前先蓄力 **1.5 秒**，把这一轮每一条弹道都用红色虚线画出来，
  末端带一个点，外加一圈"1 秒后弹幕会到达这里"的虚环。角度在蓄力开始时就锁死，
  所以看到什么就一定会打出什么。这是全场唯一有完整预告的招式，也是玩家规划路线的依据。
- **扇形（有预警）**：发射前蓄力 **1.0 秒**，在场上画出一块**黄色扇形区域**，范围就是子弹的落点范围。
  瞄准方向在蓄力开始时就锁死，所以扇形指哪打哪。这是"看预告躲"的第二招。
- **螺旋**：持续搅拌场地，让玩家没法一直待在角落蓄力。
- **受击反击**：Boss 身上常驻 **3 / 4 / 5 个箭头**（按难度），一直在转（整体 1.15 rad/s 旋转 +
  每个箭头独立摆动 0.30 rad），所以朝向永远在变、也不会一直保持标准十字。你撞中它的瞬间，
  只从这些箭头当前指的方向各打 1 发（145 px/s，出生点 92 px）。**撞之前先看箭头指哪**，是这招的全部玩法。

### 7.4 节奏参数

| 参数 | 值 |
| --- | --- |
| 登场时间 | 0.7 s（期间不出招） |
| 圆形弹幕预警 | **1.5 s**（按现实时间算，不吃慢放） |
| 反击箭头 | 4 个，整体 1.15 rad/s 旋转 + 各自摆动 0.30 rad |
| 受击无敌 | 0.45 s |
| 受击硬直 | 0.5 s（停火，给玩家撤离窗口） |
| 登场横幅 | 「环 · 守门者 / 三滴血。撞它三次。」 |

### 7.5 第二只 Boss ·「壁」

一只把自己包在**三块旋转护盾**里的装甲核心。

| 项目 | 数值 |
| --- | --- |
| 血量 | **6** |
| 半径 | 58 |
| 移速 | 1 号 Boss 的 **75%**（振幅与频率都乘 0.75） |
| 护盾 | **3 块弧形圣盾**（面积 2.5×），绕本体半径 112 旋转，每块 **2 点耐久** |
| 盾转速 | 0.75 rad/s；血量 ≤3 时 ×1.15；≤2 时 ×1.35 |

**弧形圣盾**是常驻碰撞体：撞上去只会掉盾的耐久（2 下碎一块），本体不掉血。
圣盾是金色的弧形板（金边 + 十字徽记 + 两颗耐久宝石 + 流动光点），
本体也套了一圈金色光环、六角顶点镶金钉、核心刻十字——神圣 / 中世纪味道。

要打本体的 6 点血，得从盾与盾之间的缝里钻进去。

**招式**

| 招式 | 参数 | 说明 |
| --- | --- | --- |
| **直线快弹** | **1120 px/s**，长方形弹（面积 ×2），每 2.8 s | 开火前有 0.55 s 的瞄准线；出膛带**金色闪光**，飞行时拖着**金→棕的粒子尾迹**；命中玩家会**限速 65%** |
| **扇形弹幕** | 5 + 难度（0/+1/+2）发，215 px/s，每 3.2 s | 1 秒黄色扇形预警，方向锁死 |
| **阶段爆发** | 血量 ≤3、≤2 时各一次 | 立刻连打 **3 轮**扇形（0.22 s 间隔） |

**撞到玩家**（无论撞板还是撞本体）：

1. 弹开
2. 速度 ×**0.75**（减速 25%）
3. **3 秒**内出膛极速只能到平时的 **50%**（盾球就是 0.9 × 0.5 = 45%）

减速期间球外会有一圈蓝色虚线环，提示"现在跑不快"。

## 8. 场地（TileMap）

场地不再随机撒石头，改成用 Godot 的 **TileMapLayer** 搭一张固定地图：

| 项目 | 规则 |
| --- | --- |
| 图块 | 32 px；地板 4 种、墙 4 种、墙顶 2 种（`assets/tiles.png` + `scenes/tileset.tres`） |
| 地图 | 40 × 22 格（1280 × 704），`scenes/arena.tscn` 里两层：Floor / Walls |
| 布局 | **直接在编辑器的 2D 视图里画**：打开 arena.tscn → 选中 Floor / Walls 层 → 右下角 TileMap 面板选图块 → 涂 |
| 碰撞 | 墙格在 `_ready()` 时**贪心合并成矩形**（约 18 块），再复用旧的"矩形 vs 圆"解算。**画完就有碰撞，不用手摆碰撞体**；游戏里按 **F3** 显示碰撞箱 |

**三个作用**

1. **挡球**：撞上去按法线反弹（保留 95% 速度），并**储存 1 次变向**——和撞墙同价。
2. **挡子弹**：子弹打上去直接被吸收。所以它既是掩体，也是你冲刺路线上的障碍。
3. **参与预测**：瞄准时的虚线会把墙算进去，你能直接看到"打这面墙、弹到哪"。

**为什么用 TileMap 而不是随机多边形**：地图从此是"可设计"的——掩体位置固定，玩家能记住、
能规划弹射路线；同时渲染交给引擎的批处理，比每帧 `draw_polygon` 更省。

**Boss 擂台区必须留空**：Boss 是贴脸出弹的（四向反击从 92 px 射出）。如果它飘到墙上方，
子弹一出生就会被吃掉，整招直接失效。所以 ASCII 地图的中间区域刻意不放墙。

## 11. 技术实现

### 10.1 节点结构

```
Main (Node2D)
├─ World (Node2D)            ← 震屏只晃这个
│  ├─ Bullets (Node2D)       子弹容器
│  ├─ Entities (Node2D)      Player / Boss
│  └─ FX (Node2D)            粒子与冲击波
└─ UI (CanvasLayer)
   └─ HUD (Control)          标题 / 战斗 / 结算，全部 _draw() 即时绘制
```

### 10.2 关键点

| 问题 | 做法 |
| --- | --- |
| 时间倍率 | `Engine.time_scale` + 现实时间缓动；实体只吃 `delta` |
| 弹弓输入 | `Mode{IDLE, AIMING, FLYING}` 三态机；按下进入瞄准（球继续飞）、矢量 = 鼠标−球心实时更新、松手发射 |
| 力度映射 | `lerp(320, 980, clamp(球到鼠标距离 / 230))` |
| 引导拖尾 | 瞄准时在球心放一个**数值完全相同的隐形球**，按同一套物理（出膛速度 / 摩擦 / 反弹损耗 / 障碍解算）**模拟 1.5 秒**，把轨迹画成**由粗到细、由实到虚的拖尾**：起点 = 球心，末端 = 1.5 秒后隐形球所在位置；每帧重算，松手即清除 |
| 场地 | TileMapLayer 画图；墙格贪心合并成矩形；圆-矩形用"最近点"解算穿透深度，子弹用点-矩形判定 |
| 撞击判定 | 每物理帧 `get_overlapping_areas()`，不用 `area_entered` |
| 碰撞层 | 层1 玩家 / 层2 子弹 / 层3 Boss |
| 无美术资源 | 所有图形用 `draw_circle` / `draw_arc` / `draw_line` 画 |
| 无字体资源 | `SystemFont` 依次尝试 雅黑 → 苹方 → 思源 → 系统默认 |
| 性能保护 | 同屏子弹上限 180，粒子上限 400 |
| 可调平衡 | 全部数值集中在 `scripts/config.gd` |

### 10.3 验证方式

- `-- --selftest`：24 项机制自检（难度血量、力度映射、死区、变向次数、撞墙 +1、
  时间倍率三态、撞击三下、中弹、困难即死），失败返回非零退出码。
- `-- --shot=play|fast|phase3|win|lose`：自动截图，用于回归检查画面。

## 14. 已知取舍

| 取舍 | 原因 |
| --- | --- |
| 一次拖动只给一个矢量 | "实时跟随"会让玩家一直微调，失去"承诺感"；这正是本次改版的核心 |
| 空中只有 1 次变向 | 保留反悔空间，但不允许无限修正 |
| 球会自己滑停（4 秒） | 给"没有变向次数"的时刻一个自然的结算点 |
| 障碍物对球和子弹都是实心的 | 只挡球不挡弹会造成"为什么子弹能穿过去"的困惑；实心也让掩体真正有价值 |
| 障碍物不进入 Boss 擂台区 | 否则 Boss 贴着障碍物出弹，子弹一出生就被吃掉 |
| 时间规则从"按住=全速"改为"飞行=全速" | 按住时球是停的，若世界全速，瞄准就变成站桩挨打 |
| 只有撞击一种攻击 | 保持"身体即武器"的单一表达 |
| 只有一个 Boss | 先把"发射 → 反弹 → 变向"这条核心做扎实 |
| 无音效 | 原型阶段优先验证输入手感 |
| 中文依赖系统字体 | 发布时需内嵌子集字体 |
