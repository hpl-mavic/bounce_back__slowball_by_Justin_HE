# SLOWBALL · 慢球

> 在 0.1 倍速的世界里，只有你**按住鼠标**的那一刻，时间才恢复正常。
> 你是一颗球，用身体去撞碎三滴血的守门者。

Godot 4.7 + GDScript 的俯视角动作 / 弹幕原型。**零美术资源**：所有画面都是代码画出来的圆和线，UI 用 `SystemFont` 调用系统字体。

![标题](shots/title.png)

---

## 运行

用 Godot 4.7 打开 `project.godot`，按 **F5**。

命令行：

```powershell
godot --path . --resolution 1280x720
```

> 首次用命令行运行前，建议先用编辑器打开一次让 Godot 完成资源扫描。

## 操作

一次拖动 = 一次发射。球不会跟着鼠标走。

| 操作 | 效果 |
| --- | --- |
| **按住左键** | 进入瞄准：世界进入 **0.1 倍速**，球保持原速继续飞（不会停下） |
| **移动鼠标** | 矢量从**球心**指向鼠标：方向 = 球→鼠标，力度 = 距离（0–230 px），箭头实时跟随 |
| **松开** | 球按这个矢量飞出去，世界回到 **1.0 倍速** |
| **滞空时再按住** | 消耗 1 次变向机会，边飞边重瞄 |
| **按住右键**（盾球） | 维持护盾（消耗充能，最多 1.5 s），松手立刻关盾并开始回充（2 s 充满） |
| **按住右键**（虫球） | 把世界压到 **0.05×**，松手恢复；每碰 5 次进化一档，共 5 档 |
| 撞墙 | 反弹，**储存 1 次变向** |
| 撞 Boss | 造成 1 点伤害，被弹开，**储存 1 次变向** |
| `1` `2` `3` | 标题界面选择难度 |
| `Q` / `E` | 标题界面切换角色 |
| `空格` / `Enter` | 开始（战斗中：空格 = 暂停 / 继续） |
| `R` | 重开 |
| `Esc` | 回标题 |
| 窗口失焦 | 自动暂停；切回来点一下画面，倒数 3 秒后继续 |

## 核心规则

- **攻击 = 撞击**，一次 1 点伤害。Boss 3 滴血 → 必须命中 3 次。
- **难度**：简单 5 血 / 3 个反击箭头，普通 3 血 / 4 个，困难 1 血 / 5 个。
  Boss 血量、弹幕数量与弹速、速度完全一致。
- **三个角色**：游球（标准速度；每反弹一次 **+2% 极限速度**，最多 20 层 = +40%，保持 4 秒后每 0.2 秒掉一层）、盾球（0.9× 速度、反弹损耗更大、右键护盾）、
  虫球（70% 体积、5 次变向、右键 0.05× 慢放、每碰 5 次进化，满级获得抗伤护盾 / 撕裂 / 冲刺）。
  英文名：RANGER / AEGIS / INSTAR（Instar = 螳螂两次蜕皮之间的龄期，对应五段进化）。
- **球在飞 = 世界 1.0 倍速；抓住球 = 世界 0.1 倍速。**
  你不动，世界几乎静止；你一松手，子弹也跟着飞起来。
- **空中只有 1 次变向**（撞墙 / 撞障碍物 / 撞 Boss 会各储存 1 次，最多 3 次）。
  所以每一次发射都是承诺：方向要准，力度要够。
- **手绘素材随时换皮**：把 PNG 丢进 `assets/sprites/` 并改成约定名，游戏就用图片；没有就继续用代码画。
  完整清单见 `assets/sprites/README.md`，模板用 `godot --headless --script res://tools/make_art_templates.gd` 生成。
- **中 / 英文切换**：标题页右上角点「中文 / EN」，或按 **L**；选择会存到 `user://settings.cfg`。文案全在 `scripts/i18n.gd`。
- **两关独立可选**（标题页「关卡」一行点选）：
  「环」（3 血，受击反击）、「壁」（6 血，3 块金色弧形圣盾 + 直线快弹 + 撞击减速）。
- **场地用 Godot 的 TileMap 搭**（arena.tscn + tileset.tres）：**你在 Walls 层涂什么，碰撞就自动是什么**，
  不需要手摆碰撞体；游戏里按 **F3** 可以把碰撞箱画出来对照。挡球会反弹（还给 1 次变向），挡子弹会被吸收。
- **Boss 的圆形弹幕有 1.5 秒预警**：发射前会把九条弹道用红色虚线全部画出来，
  角度提前锁死——看到什么就一定打出什么。

## 碰撞层

| 层 | 使用者 | 说明 |
| --- | --- | --- |
| 1 | Player | 主角 |
| 2 | Bullet | 子弹（mask=1，只打主角） |
| 3 | Boss | Boss（layer=4，player mask 包含它） |

主角的撞击判定用**持续重叠检测**（`get_overlapping_areas()`）而不是只依赖 `area_entered`，
否则贴着 Boss 站着时不会再次触发进入事件，会出现"撞不出伤害"的 bug。

## 开发命令

```powershell
# 机制自检：难度血量 / 时间倍率 / 撞击三下击破 / 中弹 / 困难一碰即死
godot --headless --path . -- --selftest

# 自动截图到 shots/（需要窗口，不能 --headless）
godot --path . --resolution 1280x720 -- --shot=title|play|fast|phase3|win|lose
```

自检输出示例：

```
===== SLOWBALL SELFTEST =====
  [PASS] 难度[简单] 主角血量 = 5
  ...
  [PASS] 撞击 3 次击破 Boss（实际生效 3 次）
  [PASS] 困难 1 血被命中 -> 失败状态
===== ALL PASS（失败 0 项）=====
```

## 已知取舍

- 没有音效。撞击、受击、开火的反馈目前只有画面（震屏 / 火花 / 白闪）。
- 中文 UI 依赖系统字体（雅黑 / 苹方 / 思源）。打包发布时应内嵌一份中文子集字体。
- 只有一个 Boss、一个场景，没有存档与设置菜单。
- 难度只改血量与反击箭头数是**刻意的设计约束**，不是没做完：详见 `docs/大纲.md`。
